# WBook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Запустить общую веб-библиотеку и читалку по удержанию для проверки с телефона.

**Architecture:** Серверное приложение Sites с D1-каталогом и R2-файлами. Клиент извлекает текст документов и хранит личный прогресс. Нормализованный текст общий; позиция каждого браузера отдельная.

**Tech Stack:** TypeScript, React, Vinext, Cloudflare D1/R2; JSZip для ZIP-контейнеров, PDF.js для PDF, адаптер MOBI/AZW3 из foliate-js. Точные версии закрепляются lockfile.

**Spec:** `docs/superpowers/specs/2026-10-31-wbook-reader-design.md`

## Global Constraints

- Общая библиотека на сервере; без собственных аккаунтов.
- EPUB, FB2/FB2.ZIP, PDF с текстом, TXT, DOCX, MOBI/AZW3 без DRM.
- Без OCR; файл до 25 МиБ, извлечённый текст до 10 МиБ UTF-8.
- Удержание читает; вверх ускоряет, вниз замедляет; отпускание и отмена останавливают.
- Старт 300, диапазон 60–1200 слов/мин; полный текст постоянно доступен.
- Пользователь одобрил описание и явно поручил реализацию и запуск на хосте. Выполняем в текущей сессии без повторного согласования плана.

## Review Focus

- Отпускание вне области, pointercancel и смена вкладки: чтение останавливается.
- Очень длинная книга: прокрутка до любого места доступна без обрезания текста.
- Два браузера: общие книги, раздельный прогресс.
- Архивы, DRM, повреждённые и пустые документы: понятная ошибка, без готовой пустой книги.
- Мобильная сеть и HTTP в LAN: импорт TXT/книг не зависит от secure-context-only API.
