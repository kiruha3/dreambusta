# DreamBusta Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. User requested continuous execution.

**Goal:** Independent full-content hybrid search and grounded answers with working source navigation.

**Architecture:** Owned SQLite FTS/vector index and structural chunks in Node. Local Ollama model adapter, bounded indexing queue, server-authorized retrieval and generation; Vue global search dialog adapted from TH interaction concepts.

**Tech Stack:** Node 24, SQLite FTS5, Vue 3, existing PDF.js, local Ollama; no added dependencies.

**Spec:** docs/superpowers/specs/2026-11-12-search-design.md

## Global Constraints

- Only DreamBusta files; preserve data and originals; no TH network calls or credentials.
- Model runtime defaults to loopback Ollama; recoverable lexical fallback.
- Hidden, closed, deleted and stale sources never leak in results or answers.
- PDF page / slide / publication page / paragraph source locations survive links.

## Review Focus

- Russian text, punctuation-only queries, literal HTML and long paragraphs.
- Version replacement and deletion during embedding or generation.
- Filtering before pagination/counts, anonymous versus editor access.
- Deep links overriding saved viewer position and stale URL version detection.
- Runtime failure, malformed embeddings/citations, outdated UI responses and mobile keyboard focus.
