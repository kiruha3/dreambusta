# Knowledge UI and widgets implementation plan

**Goal:** выполнить 10 согласованных пунктов UI и внешнего помощника DreamBusta.
**Spec:** ../specs/2026-11-12-knowledge-ui-widgets-design.md
**Architecture:** Vue/Node24/SQLite; TH только как read-only образец.

- [x] Публичные настройки меню/knowledge-флаг и кабинет редактора: HTTP регрессии,
      shared/types.ts, server/app.ts, src/pages/Settings.vue и новый Admin.vue.
- [x] Навигационный контекст и полноширинный поиск: helper URL, App.vue,
      Catalog/Collection/MaterialCard, согласовать Material.vue с исполнителем.
- [x] Чтение и PDF: Material.vue, Reader/BookText, отдельные стили;
      интервалы, ширина, скрытие панелей, крошки и понятные кнопки PDF.
- [x] Внешний виджет: server/widgets.ts + статические assets, типы, scoped search;
      HTTP тесты, изолированное iframe и скрипт вставки. Корневой обработчик интегрирует root.
- [x] Настройки виджетов и кабинет: CRUD, выбор материалов/origin, публикация,
      код кнопки/блока и preview. TH UX адаптирован без подключения его API.
- [x] Проверка ресурсов, E2E и review всего diff; npm test/typecheck/build/E2E,
      реальные рабочие API и сохранность библиотеки. Обновить docs и коммит.

Не разворачивать на VPS. Не изменять исходники/данные ТХ и Академии.

## Итоговая проверка

- Node 24: 129 unit/HTTP тестов, typecheck и production build.
- Browser E2E: основное приложение, поиск/помощник, чтение и контекст,
  кабинет/меню/knowledge, внешнее встраивание на отдельном origin.
- Проверены 176 доступных ресурсов изображений/иконок сохранённых публикаций:
  браузер декодировал все. Импорт для аудита не обновлялся.
- Все 14 рабочих материалов остались на месте. Во время работы витрина была
  отдельно обновлена через её интерфейс (363 вложенные страницы сохранены);
  это обновление оставлено, сравнивается с отдельным локальным снимком.
- Заключительный review: исправлены handshake предпросмотра и общий лимит
  клиентов за reverse proxy; повторный review чтения без важных замечаний.
- Локальный сервис перезапущен с новыми API. VPS не изменялся.
