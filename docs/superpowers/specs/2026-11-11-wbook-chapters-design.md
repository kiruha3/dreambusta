# WBook: чтение по главам

Пользователь 11 ноября подтвердил: главы находятся внутри одной читалки, а режим «Скорочтение» называется WBook. Отдельная вкладка «Текст» сохраняется. Это уточняет согласованное предложение предыдущего сообщения.

- Галочка «Читать по главам» ограничивает контекст выбранной главой. Отключение возвращает полный текст; глобальная позиция слова сохраняется.
- По умолчанию используется оглавление EPUB, затем автоматический поиск коротких заголовков («Глава 1», «Глава первая», «Часть II», chapter/part, пролог/эпилог).
- Для нестандартных книг можно задать буквальное начало заголовка, просмотреть результат и применить. Тело абзаца с упоминанием слова не является границей. Нулевая выборка не заменяет рабочее оглавление.
- Предыдущая/следующая глава и оглавление с поиском доступны в WBook. Чтение останавливается в конце главы, следующая открывается явно. Текст до первого заголовка остаётся доступен как вступление.
- Настройки разбивки и переключатель сохраняются в этом браузере на версию материала, как существующий прогресс. Метаданные родного оглавления сохраняются вместе с книгой.
- Рассмотрены: только эвристика (быстро, но теряет родное оглавление), только EPUB (не покрывает TXT/MD), родное оглавление с авто/ручным запасным вариантом. Выбран последний, как предложено и подтверждено пользователем.
- Изменения только локально на 5173. Исходники книг, URL, метаданные, textVersion и ранее сохранённые позиции не меняются при добавлении оглавления к существующим книгам. Поле режима в localStorage остаётся speed для совместимости.

Реализация: необязательные главы {title, paragraph}, границы в индексах исходных абзацев. Виртуальный текст сохраняет глобальные индексы слов. Нет внешних запросов, новых зависимостей и регулярных выражений от пользователя.
