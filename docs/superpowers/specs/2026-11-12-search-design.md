# Поиск и ответы Дримбусты

Пользователь 12 ноября согласовал поведение общего поиска и ответов по источникам,
уточнил «тексты», затем выбрал собственную реализацию без сервиса Теххелпера и
поручил закончить разработку и проверки без промежуточных согласований.

## Подход

Рассмотрены локальный полнотекстовый поиск и гибридный поиск. Выбран гибридный:
SQLite FTS5 + локальные эмбеддинги + reciprocal rank fusion, как в поисковом
конвейере ТХ. Переносим концепцию разбиения, ранжирования, окна и проверки
источников; зависимости от Django, AIMOS, ТХ, Qdrant и их данных нет.
Ollama используется только как локальный runtime моделей: embeddinggemma для
векторов и gemma4:e2b для ответа. Модели уже установлены. Код поиска, очередь,
векторы, FTS, фильтрация и RAG принадлежат Дримбусте. Параметры runtime задаются
на сервере; браузер не получает доступ к нему. При его отказе работает FTS.

## Поведение

- Поиск из любой страницы через кнопку и Ctrl/Cmd+K; адаптивное диалоговое окно.
- Фильтры типа, подборки, текущего материала. Ищем метаданные и весь доступный
  текст, включая все страницы публикации и расшифровки медиа.
- Выдача показывает название, местоположение и цитату с подсветкой. Клик ведёт
  к абзацу книги/текста, странице PDF, слайду или странице публикации.
- В индексе хранятся только реальные извлечённые тексты. Сканы без OCR и медиа
  без расшифровки ищутся по метаданным.
- Отдельное действие «Спросить по найденному»: не более шести актуальных
  фрагментов, ответ с проверяемыми ссылками [1], [2]. При отсутствии источников
  или модели честное сообщение, без выдуманного ответа.
- Обновление индекса при добавлении, редактировании, обновлении и удалении;
  индекс восстанавливается из библиотеки после перезапуска. Очередь эмбеддингов
  ограничена, поддерживает повтор и отменяет устаревшую работу.
- Перед выдачей и до/после генерации проверяются существование, доступность,
  версия и хеш источника. Скрытые материалы доступны только редактору;
  закрытая библиотека требует входа. Изменение доступа во время запроса
  аннулирует ответ. Содержимое источников считается данными, не инструкциями.

## Ограничения и проверка

Правим только DreamBusta; исходная библиотека и оригиналы сохраняются. Рабочую
удалённую витрину не восстанавливаем. Без публикации на сервер. Никаких новых
внешних сервисов и ключей ТХ. Сначала тесты на индекс/HTTP/гонки, затем код;
браузерные проверки окна, переходов, мобильного режима и ответов. Обязательны
npm test, npm run typecheck, npm run build, npm run test:e2e и проверка реальных
локальных моделей на временной библиотеке.
