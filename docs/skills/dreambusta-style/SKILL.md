# Стиль Дримбусты

Спокойный интерфейс для работы с материалами: Geist, нейтральные поверхности, тонкие границы, компактные инструменты, ровная сетка. Цвет выделяет обложки и состояния. Основа взята из Теххелпера; функциональность и зависимости Теххелпера для применения стиля не нужны.

## Как применять

1. Прочитай [design-system.md](references/design-system.md): точные размеры, палитра, поведение читалки и помощника.
2. В существующей Дримбусте используй её переменные и компоненты. В другом проекте перенеси [dreambusta-tokens.css](assets/dreambusta-tokens.css) вместе с папкой `fonts/`, затем адаптируй разметку к его стеку. CSS содержит шрифты и обе темы; это основа оформления, а не полный UI-kit.
3. Сохрани структуру и назначение целевого продукта. Стиль не требует копировать разделы библиотеки, менять фреймворк или переносить сервер.
4. Проверь итог на широком экране и телефоне, с длинными русскими названиями, пустым состоянием и тёмной темой. В изменённых интерактивных компонентах проверь клавиатуру и состояния загрузки.

## Опорные решения

| Элемент | Применение |
|---|---|
| Типографика | Geist 400/500/600; интерфейс 14px/1.5; статья и текст — line-height 1.6 |
| Поверхности | Белый фон, графитовый primary, серые границы; тёмная тема через те же семантические токены |
| Сетка | Одинаковые края и высоты соседних элементов; контейнер задаёт gap; карточки не подскакивают на hover |
| Поиск | В верхней общей панели, занимает доступную ширину; вспомогательные действия компактны справа |
| Навигация | Иконка фиксированной ширины, текст в отдельной колонке; breadcrumbs сохраняют путь через подборку |
| Чтение | Просмотрщик занимает ширину рабочей области; колонка текста центрируется внутри; прокрутка внутри статьи/текста |
| Правая панель | «Оглавление» и «О материале» — компактные кнопки справа от просмотрщика; панель можно скрыть, границу перетащить |
| Помощник | Кружок превращается в чат на том же месте; при открытом чате отдельного кружка нет; закрытие крестиком справа сверху |

## Тексты и детали

Используй короткие функциональные подписи: «База знаний», «Материалы», «Подборки», «Оглавление», «О материале». Сообщения объясняют состояние и доступное действие. Без рекламных слоганов, выдуманной статистики и технических подробностей, которые не помогают пользователю.

Иконки интерфейса — Lucide или совместимые SVG с одинаковой толщиной линии. У кнопок без текста есть доступное имя и подсказка. Иконки импортированных публикаций сохраняют исходный вид: собственный SVG/изображение или emoji, а не случайный символ из другого шрифта.

## Частые ошибки

- Большой line-height интерфейса и разреженные абзацы: различай 1.5 для оболочки и 1.6 для чтения.
- «На всю ширину» как растягивание каждой строки: растягивается рамка просмотрщика; текст ограничен выбранной шириной и остаётся выровнен слева.
- Несколько вложенных вертикальных скроллов: основной контент читает один внутренний scroll-контейнер; оглавление может прокручиваться отдельно.
- Смещение страницы при появлении инструментов: держи место панели и scrollbar стабильным.
- Цветной primary, градиенты и тяжёлые тени по умолчанию: используй нейтральные токены; акценты берутся из содержимого и статусов.

Исходная привязка справочника: DreamBusta, коммит `62ad3b2`, 12 ноября 2026. При работе с более новой версией сверяйся с её действующими компонентами и последними указаниями пользователя.
