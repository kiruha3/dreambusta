# DreamBusta — макеты перед реализацией

Версия 1 · 11 ноября 2026 года.

Откройте [галерею 30 экранов](index.html). Каждый экран доступен в PNG и в редактируемом HTML. Для просмотра без сервера можно открыть index.html двойным щелчком: картинки и навигация работают локально.

В комплекте:

- 30 PNG в png/: каталог, подборки, все способы чтения/просмотра, управление, важные состояния, три мобильных экрана, тёмная читалка, Buildin и окно читаемой ссылки;
- 30 статических HTML в screens/;
- [карта экранов и состав будущей реализации](../../superpowers/specs/2026-11-11-dreambusta-screens-design.md);
- [общие требования, редакция 9](../../superpowers/specs/2026-11-11-dreambusta-library-design.md);
- [проверка и границы результата](review.md), verification.json с техническим отчётом;
- обзорные листы overview-*.png;
- screens.cjs и style.css — исходники макетов; build.cjs — экспорт; manifest.json — перечень изображений;
- research/buildin-review.md — наблюдения по присланной публичной ссылке;
- три шрифта Geist из TechHelper в assets/.

Визуальный метод: точные HTML/CSS-макеты отрисованы Chromium через Playwright в PNG. Генеративная модель изображений не использовалась. Это позволяет сохранить кириллицу, одинаковую сетку и точные подписи. Фотографии и сторонние обложки не использовались; обложки демонстрационные и нарисованы средствами CSS.

Приложение не реализовано. Кнопки внутри макетов статические; работает навигация самой галереи. Все материалы, обложки, статусы обработки и адрес techhelper.example.org — демонстрационные данные. Buildin — пример по присланной странице; основной текст адаптирован для макета, это не работающая интеграция.

## Важные решения

Share-материал хранит полученную публикацию, дату и источник. Чтение не загружает страницу заново. При ручной попытке обновления с отказом источника прежнее содержимое остаётся видимым; редактор видит предупреждение перед завершением обновления с потерей доступа. Закрытый оригинал не запрашивается.

Адреса DreamBusta читаемые: /library/reglament-soglasovaniya и /collections/start-v-dreamdocs. Внутренний ID отделён от адреса; при явной смене slug старый адрес перенаправляется. Формат чужой share-ссылки не изменяется.

## Повторный экспорт

Нужны Node.js, Playwright с Chromium и sharp. Эти библиотеки доступны в bundled workspace runtime Codex; в приложение зависимости не устанавливались.

```powershell
$env:NODE_PATH = 'C:\Users\kirill\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules'
& 'C:\Users\kirill\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' .\build.cjs
```

Для просмотра в браузере с локального сервера:

```powershell
node .\serve.cjs 5318
```

Адрес: http://127.0.0.1:5318/mockups/2026-11-11/index.html

Сервер читает только docs/ и слушает loopback; публикации на внешний хостинг нет.
