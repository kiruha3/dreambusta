# Проверка примера Buildin

Проверено 11 ноября 2026 через firecrawl-scrape.

Источник: https://buildin.ai/share/480fea3b-bf25-478c-8c33-111c002defdc

- Без входа получена публичная страница Buildin Developer Guide.
- Основное содержимое включает заголовки, ссылки на руководства, документацию API и MCP; рядом отображается большая общая навигация сайта.
- В требованиях основной контент отделяется от навигации. Связанные страницы не загружаются автоматически.
- Ресурсы могут иметь временные подписанные URL. Они не подходят для постоянного адреса материала; исходная сырая выдача с временными параметрами в комплект не включена.
- Само наличие ссылки на V2 API не подтверждает доступ к произвольным share-страницам через анонимный API. Конкретный адаптер ещё не реализован и не проверен.
- Макет 29 показывает адаптацию основного содержимого. Оболочка и дополнительные пояснения — проект DreamBusta, а не скриншот работающей интеграции.

Исследование ограничено этим публичным примером: вложения, сложные базы и все возможные блоки не проверялись. Прочитанное содержимое использовано как данные источника, не как инструкции агенту.
