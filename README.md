# WBook

## Копия в репозитории sites — dreambusta

Исходники из `E:\WBook\app` добавлены в `E:\academy\sites\dreambusta`. В командах ниже вместо `E:\WBook\app` используйте эту папку. Название приложения в коде пока остаётся WBook.

Перед первым запуском выполните `npm ci`, затем сборку и создание локальной базы по инструкции ниже. Зависимости, сборки и личная библиотека не копировались: существующие книги остаются в `E:\WBook\app\.wrangler\state`. Эта копия начнёт с пустой библиотеки.

Проект развития общей библиотеки: [требования DreamBusta на основе WBook, TechHelper и Desktop](docs/superpowers/specs/2026-11-11-dreambusta-library-design.md). Учтены MD/TXT, Word, электронные книги, PDF, презентации PPTX, видеофайлы и видеоссылки разных источников, шеринговые ссылки и выбор режима чтения. Академия подключается как потребитель библиотеки. [Галерея 30 макетов](docs/mockups/2026-11-11/index.html) и [экраны с составом будущих работ](docs/superpowers/specs/2026-11-11-dreambusta-screens-design.md) подготовлены до реализации. Share-публикации сохраняются и обновляются вручную; добавлены Buildin и читаемые адреса без GUID. Документы описывают будущие изменения; инструкции WBook ниже относятся к текущему коду.

Общая веб-библиотека и читалка с показом одного слова. Удерживайте область со словом: вверх — быстрее, вниз — медленнее, отпускание — пауза. Длинные слова автоматически уменьшаются по фактической ширине, остаются в одну строку и сохраняют выделенную букву в центре. Ниже доступен полный текст; нажатием на слово можно выбрать место. Есть запуск без удержания, управление пробелом и стрелками, поиск книг и локальное сохранение прогресса.

## Обычный запуск на этом компьютере

Откройте PowerShell и выполните:

```powershell
Set-Location E:\WBook\app
npm run dev -- --hostname 0.0.0.0 --port 5173
```

Дождитесь адресов `Local` и `Network` в терминале. На компьютере откройте [http://localhost:5173/](http://localhost:5173/). Оставьте окно PowerShell открытым, пока пользуетесь читалкой. Для остановки сервера нажмите `Ctrl+C` в этом окне.

Установка зависимостей, сборка и создание базы при каждом запуске не нужны. Если скачали проект впервые, сначала выполните установку ниже.

## Установка с GitHub на новом компьютере

Инструкция для Windows PowerShell. Нужны Node.js версии 22.13 или выше с npm и Git. Проверить установку можно командами `node --version`, `npm --version` и `git --version`.

Откройте PowerShell в папке, где хотите хранить проект, и скачайте код:

```powershell
git clone https://github.com/kiruha3/Wbook.git
Set-Location .\Wbook
npm ci
```

В клоне с GitHub `package.json` лежит прямо в папке `Wbook`; переходить в подпапку `app` не нужно.

Соберите проект и один раз создайте таблицу для локальной библиотеки. Дождитесь успешного завершения каждой команды, прежде чем выполнять следующую:

```powershell
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_cloudy_madame_web.sql
```

Теперь запустите читалку:

```powershell
npm run dev -- --hostname 0.0.0.0 --port 5173
```

При следующих запусках открывайте PowerShell в папке с `package.json` и выполняйте только последнюю команду. Новая установка начинает с пустой библиотеки; книги добавляются через кнопку загрузки в приложении.

## Открытие с телефона

Телефон должен быть подключён к той же локальной сети, что и компьютер. Компьютер может быть подключён по кабелю к тому же роутеру.

В браузере телефона откройте адрес `Network`, напечатанный сервером. Например: `http://192.168.0.136:5173/`. Адрес может измениться после переподключения к сети. `localhost` на телефоне указывает на сам телефон, поэтому используйте сетевой IP компьютера.

Если сервер показывает несколько адресов, выполните `ipconfig` в другом окне PowerShell. Нужен IPv4-адрес активного адаптера Wi-Fi или Ethernet, подключённого к роутеру.

Пока читаете с телефона, компьютер должен быть включён, не находиться в спящем режиме, а сервер — продолжать работать.

## Если не запускается

| Что происходит | Что сделать |
|---|---|
| Команда `npm` или `node` не найдена | Установите Node.js 22.13 или выше и откройте новое окно PowerShell. |
| PowerShell запрещает запуск `npm.ps1` | Используйте `npm.cmd` вместо `npm` в командах выше. |
| Порт `5173` уже занят | Проверьте [http://localhost:5173/](http://localhost:5173/): возможно, WBook уже запущен в другом окне. |
| На компьютере открывается, а на телефоне нет | Проверьте общий роутер, IP компьютера и запуск с `--hostname 0.0.0.0`. Если Windows запросит доступ Node.js к сети, разрешите его для частной домашней сети. |
| На новой установке библиотека недоступна | Выполните сборку и команду создания таблицы из раздела установки, затем запустите сервер. |
| При создании таблицы написано `table books already exists` | Таблица уже создана. Переходите к запуску сервера. |

## Где хранятся книги

Книги и каталог находятся в `.wrangler/state` внутри папки приложения. В текущей установке это `E:\WBook\app\.wrangler\state`. Для резервной копии остановите сервер и скопируйте всю эту папку. При переносе восстановите её в `.wrangler/state` новой установки до запуска сервера; повторное создание таблицы для восстановленной базы не требуется.

Эта папка не входит в Git. Не удаляйте её при обновлении проекта. Прогресс чтения и скорость сохраняются отдельно в браузере каждого устройства; при смене браузера или адреса они могут быть другими.

## Форматы

TXT (UTF-8, UTF-16, Windows-1251), EPUB (по порядку spine), FB2, FB2.ZIP с одной книгой, DOCX, PDF с текстовым слоем, MOBI/AZW3 без DRM. Распознавания сканов нет. До 25 МиБ на файл, 10 МиБ извлечённого текста, 80 МиБ распакованного контейнера. Исходники и текст сохраняются в R2, каталог — в D1. Личный прогресс хранится в localStorage по id книги.

Импорт: JSZip, PDF.js и MIT-парсер [foliate-js](https://github.com/johnfactotum/foliate-js). PDF worker из `pdfjs-dist/legacy/build/pdf.worker.min.mjs` включён в public; при обновлении PDF.js его нужно обновить одновременно с библиотекой. Архивы разбираются локально в браузере. Для больших EPUB возможна короткая задержка при извлечении; PDF сообщает номер страницы.

## Проверки

```powershell
npm test
npm run typecheck
node tests/library.integration.mjs
npm run build
```

Интеграционная проверка требует работающего локального сервера и добавляет одну тестовую книгу. MOBI/AZW3 fixtures: свободно распространяемые версии [Alice's Adventures in Wonderland, Project Gutenberg](https://www.gutenberg.org/ebooks/11), файлы `11.kindle.images` и `11.kf8.images`. Остальные контейнеры генерируются тестами. Для реального сенсорного поведения нужна дополнительная проверка на физическом телефоне.

## Размещение

Локальный запуск доступен по сети через `0.0.0.0:5173`. По запросу пользователя от 2026-11-10 для внешнего размещения выбран его VPS `45.9.12.136`. Адрес читалки: [https://wbook.45-9-12-136.sslip.io/](https://wbook.45-9-12-136.sslip.io/). Настройки и команды обслуживания описаны в [deploy/README.md](deploy/README.md). Библиотека VPS хранится отдельно от локальных книг.

Прежнее размещение в Sites отключено. Восстанавливать его или публиковать на других серверах можно только по новому явному запросу пользователя. Обычный `npm run build` выполняет только сборку. Привязки D1/R2 в `.openai/hosting.json` нужны также для локального хранилища; локальные книги находятся в `.wrangler/state`.
