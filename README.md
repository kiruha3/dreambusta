# DreamBusta

Самостоятельная библиотека на **Vue 3 + TypeScript + Vite**, с отдельным Node API и SQLite. Оформление взято из TechHelper; читалка и импорт книг — из WBook. Код исходного WBook сохранён в коммите `b5fb240`; его личная библиотека не переносилась.

## Запуск

Требуется **Node.js 24+**. Из этой папки:

```powershell
npm ci
npm run dev
```

- Интерфейс: http://localhost:5175/library
- API: http://localhost:5176/api/session
- Первый редактор: http://localhost:5175/login — задайте собственные email и пароль от 12 символов. Создание первого редактора разрешено только с локального компьютера. Предустановленных учётных записей нет.
- Для телефона используйте IP компьютера и порт 5175. Серверы слушают `0.0.0.0`, управление требует входа.

На этом компьютере Node 24 также доступен в комплекте Codex. При системном Node 22 запускайте так:

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" scripts/dev.mjs
```

Рабочая библиотека начинается пустой. Тесты создают временные базы и не добавляют свои материалы или редактора в рабочую `data/`.

## Что работает

- Каталог с поиском по названию, автору, описанию и тегам, фильтрами и сортировкой.
- Карточка: название, автор, описание, теги, обложка, видимость, кнопка скачивания оригинала.
- Подборки с повторным использованием материалов; порядок меняется перетаскиванием и стрелками.
- Читаемые адреса `/library/nazvanie` и `/collections/podborka`. Внутренние ID отделены от адреса. Переименование названия не меняет URL; смена адреса сохраняет прежние ссылки за тем же материалом. После удаления адрес не переиспользуется.
- Файлы загружаются потоком на диск; большие видео не загружаются целиком в память. Воспроизведение поддерживает HTTP Range.
- Оформленная статья, обычный текст и читалка WBook. Выбор конкретного слова, жест удержания и изменения скорости, пробел/стрелки, поиск, настройка шрифта. Большие книги показываются частями без создания DOM для всего текста.
- Прогресс, скорость, последний режим и избранное сохраняются в текущем браузере. Для новой текстовой версии используется отдельный ключ прогресса.
- PDF и слайды сохраняют собственную страницу и масштаб при переключении режимов и повторном открытии. Новая версия начинает отдельный прогресс. У презентаций есть миниатюры, переход по номеру, масштаб и полный экран.
- Повторное добавление той же ссылки или файла с тем же SHA-256 получает сообщение о существующей карточке. Для обновления используется её действие «Загрузить новую версию» или «Обновить из источника».
- Просмотр PDF через PDF.js, Word через readOnly-компонент TechHelper, статические слайды через парсер DreamAgent Desktop.
- Светлая/тёмная тема, интерфейс на мобильной ширине.
- Вход редактора, HttpOnly session cookie, CSRF и Origin, скрытые файлы защищены теми же правами, что и карточки. Настройка закрытого каталога.

## Форматы и ограничения

| Материал | Доступные режимы | Лимит файла |
|---|---|---|
| MD / Markdown | Статья, текст, скорочтение | 25 МБ |
| TXT, EPUB, FB2, FB2.ZIP, MOBI, AZW3 без DRM | Текст, скорочтение | 25 МБ |
| PDF | Страницы; текст и скорочтение при наличии текстового слоя | 100 МБ |
| DOCX | Документ, текст и скорочтение при наличии текста | 100 МБ |
| DOC | Преобразование в DOCX установленным LibreOffice | 100 МБ |
| PPTX | Статические слайды; текст и скорочтение при наличии текста | 32 МБ |
| MP4, WebM, MOV, M4V | Видеоплеер, при поддерживаемом браузером кодеке | 1 ГБ |
| MP3, M4A, OGG, WAV, FLAC | Аудиоплеер, при поддерживаемом браузером кодеке | 1 ГБ |

Общий извлечённый текст ограничен 10 МБ. Архивы имеют дополнительные ограничения распаковки. HTML-уроки из ZIP не импортируются; FB2.ZIP остаётся книжным форматом.

PDF без текста и DOCX без текста не отбрасываются: их можно просмотреть. OCR и автоматическая расшифровка не выполняются. Готовую расшифровку видео/аудио редактор может добавить в карточке — появятся статья, текст и скорочтение.

**DOC:** LibreOffice на данном компьютере отсутствует. Оригинал сохраняется с понятной ошибкой; после установки конвертера загрузите новую версию. Можно сразу загрузить DOCX. Переменная `LIBREOFFICE_PATH` указывает полный путь к `soffice`/`soffice.exe`. Преобразование имеет отдельный профиль и тайм-аут 90 секунд.

**PPTX:** используется статический рендер поддержанных фигур, текста и изображений. Анимация, диаграммы, SmartArt, встроенное видео, сложная вёрстка/шрифты могут отличаться от PowerPoint. Внешние связи в пакете отклоняются. Для точного визуального соответствия можно загрузить экспортированный PDF. Конвертация PPTX через LibreOffice здесь не включена.

**Word:** это просмотрщик существующего TechHelper, без функций редактирования. Сложная вёрстка может отличаться от Microsoft Word. Модуль загружается отдельно от каталога (крупный lazy chunk).

## Ссылки и сохранённые публикации

Поддержаны отдельные видео YouTube, Rutube и VK, прямые URL медиафайлов, публичные адреса TechHelper `/shared/d/...`, `/shared/...`, `/shared/kb/...`, а также Buildin `/share/...`. Неизвестный источник получает понятное сообщение, а не универсальный iframe.

Видео внешнего сервиса загружается по нажатию «Загрузить плеер». Встраивание, региональные ограничения, авторизация источника и кодек могут мешать воспроизведению; есть переход к источнику. Настоящее воспроизведение каждого провайдера требует проверки на конкретных ссылках. Наличие записи в каталоге не обещает офлайн-доступ к потоку.

Публикации сохраняют полученные HTML/текст и доступные растровые изображения. PDF TechHelper запрашивается только как **опубликованный preview**, без `variant=original`, закрытых исходников, чужих сессий и паролей. JSON документов/статей преобразуется в статью, сохраняющую базовые заголовки, списки, таблицы и опубликованный текст. Полная эквивалентность всех редакторов TechHelper не заявляется.

Buildin использует проверенный анонимный web API `api/docs/<share-id>`. Из большого ответа берутся только блоки выбранной статьи. Подстраницы остаются отдельными ссылками. Сложные блоки могут сохраняться в текстовом представлении; приватный API и логин не используются. Контракт внешнего web API может измениться.

Открытие сохранённой статьи **не обращается к источнику**. В карточке показывается дата сохранения. Обновление запускает редактор:

1. Предупреждение о возможной недоступности после обновления.
2. При успехе сохраняется новое представление.
3. При закрытии/удалении источника старая версия остаётся доступна. Можно оставить её или явно завершить обновление с потерей доступа.
4. Сетевая ошибка и тайм-аут не стирают последнюю рабочую версию.

Обновление атомарно: если не удалось получить опубликованный PDF или изображение, сохраняется вся предыдущая публикация. Одновременное изменение карточки, замена файла или явное завершение обновления отменяют устаревший результат с сообщением о конфликте; повторите действие из актуальной карточки.

Импорт выполняет только публичные HTTP(S) запросы: без логина/пароля, локальных/служебных адресов, cookies пользователя. DNS-адрес закрепляется на запрос; перенаправления проверяются заново. HTML очищается; ресурсы ограничены по размеру и типу.

## Хранение и перенос

`data/` игнорируется Git. Внутри:

- `library.sqlite`, `-wal`, `-shm`: метаданные, адреса и история slug, подборки, настройки, хеши паролей и сессии;
- `files/`: исходники и производные файлы;
- `snapshots/`: опубликованные ресурсы;
- `covers/`: обложки.

Vite запрещает прямую выдачу хранилища, включая `/@fs/`. Не размещайте `DATA_DIR` внутри `public/` или `dist/` и не задавайте корень проекта либо его родителя: приложение проверяет эту настройку при запуске. Пользовательские файлы доступны через API с проверкой прав.

Резервная копия: остановите API и скопируйте **весь каталог data/**. Для восстановления положите его рядом с исходниками либо задайте `DATA_DIR`. Не копируйте живую SQLite только одним файлом без WAL. Скопированная база включает активные сессии; для их сброса удалите строки таблицы `sessions` локальной SQLite-командой.

Смена версии сохраняет materialId, адрес, описание, обложку и место в подборках. Если обработка новой версии не удалась, старая остаётся активной. Удаление карточки закрывает API-доступ к файлам и убирает материал из подборок; отдельного сборщика оставшихся файлов и UI истории старых версий пока нет. Дисковые копии не следует считать корзиной с гарантированным восстановлением.

Исходная библиотека `E:/WBook/app/.wrangler/state` не менялась. Старые D1/R2/React-файлы сохранены как исторический код и не участвуют в Vue-сборке. Миграция их данных, SHA-адресов и localStorage не запускалась.

## Переменные сервера

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DATA_DIR` | `data` | Каталог библиотеки |
| `API_PORT` | `5176` | Порт API и цель Vite proxy |
| `API_HOST` | `0.0.0.0` | Адрес API |
| `WEB_PORT` | `5175` | Порт Vite dev |
| `SECURE_COOKIE` | выключено локально | `1` для HTTPS-размещения |
| `LIBREOFFICE_PATH` | стандартный путь / `soffice` | Конвертер старого DOC |

Для локальной проверки сборки: в одном терминале `npm run api`, в другом `npm run build` и `npm run preview`. Для самостоятельного сервера потребуется HTTPS reverse proxy, выдающий `dist/` с SPA fallback и `/api` к Node API. Доступ извне, SSO, домен, серверное резервирование и интеграция меню Академии не развёртывались.

В Академии достаточно отдельного пункта «Библиотека» со ссылкой на каталог или подборку DreamBusta. Курсы/модули LMS сюда не переносятся. Текущий API предназначен для same-origin интерфейса; настройка межсерверного доступа потребителей выполняется при размещении.

## Проверки

```powershell
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
node --experimental-strip-types tests/live-sources.mjs
```

Unit/HTTP тесты проверяют импортёры, slug/исторические адреса, SQLite, доступ/CSRF, оригиналы и Range, share-снимки и отказы обновления, конфликты операций, дубли и защиту сетевых запросов. Отдельный HTTP-тест проверяет запрет базы/WAL/исходников через Vite. Browser E2E использует временную библиотеку: создание редактора, MD, карточка/ссылка, чтение/позиция, подборка, PDF-скан, страницы PDF при смене режима/версии, readOnly Word с таблицей, порядок PPTX, 20 плотных слайдов на телефоне с масштабом/миниатюрами/полным экраном, большая книга, WAV, мобильный экран и тёмная тема. Отдельная сетевая проверка читает присланную публичную статью Buildin. Артефакты — в игнорируемой `.superpowers/e2e/`.

## Временный отдельный Git

Вложенный репозиторий находится в этой папке. Базовый коммит `b5fb240`, ветка разработки `feat/vue-library`, remote не подключён. Пока он существует, не добавляйте папку в родительский Git как submodule.

Когда будете переносить в основной репозиторий: сначала сохраните нужную историю/резервную копию, затем удалите **только `dreambusta/.git`**, после чего добавьте исходники из родительского репозитория. `data/`, `.env*`, `node_modules/`, сборки и тестовые артефакты должны остаться исключёнными.
